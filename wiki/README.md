# Research wiki

The research and design knowledge base for [Persona Project](../README.md). This directory is the wiki; it is versioned with the code.

## Start here

- [Master index](index.md): the full catalog of theory pages and research notes.
- [Desiring-machines redesign](development/desiring-machines-redesign-sketch.md): design rationale and candidate architecture.
- [Design searches](design_search/README.md): fourteen investigations connecting the research to machine design.
- [Open questions](development/open-questions.md): unresolved research and implementation questions.
- [Cited sources](cited-sources.md): references identified for further reading.
- [Archive](archive/README.md): scratch research, the original wiki plan, and the location of the local V1 prototype.

For the implemented pipeline and setup instructions, use the [project README](../README.md). Research proposals can describe behavior that the runtime does not implement.

## Where material belongs

| Location | Contents |
| --- | --- |
| `theory/` | Concept pages and connections across sources. |
| `development/` | Design syntheses, plans, and open questions. |
| `design_search/` | Research searches supporting specific design decisions. |
| `archive/` | Earlier project plans and working notes. |
| `raw/` | Local source library; excluded from this GitHub repository. |
| `index.md` | Full research catalog. |
| `log.md` | Activity record. |

Open this directory as an Obsidian vault to follow the existing `[[wikilinks]]` and graph. On GitHub, use this guide and directory listings; GitHub's Markdown view does not resolve Obsidian wikilinks.

[CLAUDE.md](CLAUDE.md) documents the wiki's source-reading, linking, and maintenance conventions. [log.md](log.md) records changes to the knowledge base.
