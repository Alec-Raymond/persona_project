The [redesign sketch](desiring-machines-redesign-sketch.md) describes the V2
direction. Each machine does a narrow task. Groups combine those outputs. An
editor updates character state and drafts the reply. A proposed ghostwriter
reviews conversations and edits the persona between sessions.

The development objective is one convincing persona first. Product-reaction
simulation and comparison with real reviewer text come later. The April log
records that ordering; it does not record a completed evaluation.

## What the working pipeline includes

1. Always-on machines run alongside machines selected by relevance and random sampling.
2. Each machine reads the same pre-turn state and produces its own output.
3. Random groups combine machine outputs using a chosen synthesis mode.
4. The editor rewrites the state and drafts a reply.
5. The armor step shapes the spoken reply.
6. A separate fit reviewer sees the situation and conversation, without the internal state.
7. Failed fit reviews trigger bounded redrafts. The last draft can still fail when the retry limit is reached.

The [pipeline](../../persona2/pipeline.py) and [prompts](../../persona2/prompts.py)
are the current source of truth. The
[prompt walkthrough](../../docs/pipeline-prompts.md) predates the armor and fit steps.

## What remains deferred

- **Compensation and habit/variation selection votes.** Selection uses relevance and random votes. The always-on Compensator machine already exists.
- **Learned firing habits.** The runtime records `fire_count`, but selection does not use it.
- **A durable memory system.** The current Memory-generator is a normal machine. There is no memory corpus or per-memory recall machinery.
- **Between-conversation persona editing.** The ghostwriter loop and immutable/mutable machine tags remain design material.
- **Conversation continuation from saved traces.** Traces support inspection and replay. They do not restore runtime state for continued chat.

These gaps appear in the walkthrough's
[deferred-scope list](../../docs/pipeline-prompts.md#9-where-the-skeleton-diverges-from-the-full-design).
The current [selection code](../../persona2/selection.py) and
[state definition](../../persona2/state.py) confirm the selector and persistence limits.
