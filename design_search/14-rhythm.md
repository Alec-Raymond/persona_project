## Key findings

### 1. Rhythm is the most dissolved category

The stub — "refrain + pulsation, merged for sobriety" — does not survive. Refrain and pulsation are distinct and resolve into *different* parts of the architecture, not into a catalog of machines. Rhythm = 1 machine + 1 emergent property + 1 ghostwriter diagnostic.

### 2. Pulsation → one machine

The carrier wave under content (tempo, cadence). Criterion (`rhythm-vs-repetition.md`): an LLM is repetitive by default, rhythmic only with "difference-with-memory-under-measure." A single always-on Pulsation machine (modulation-shaped) supplies the turn-to-turn tempo difference — the anti-isorhythmia organ. Distinct from Affect modulation (tempo vs intensity). Stage-5 literary guidance carries the prose-craft rest.

### 3. Refrain → emergent, not a machine

Refrains appear as BwO textual recurrences + `fire_count` coupling-patterns; the sketch already holds this (grooves out of scope, no separate tracking). The Beckett-Worm caveat (a stateless persona has no internal periodicity) holds but is partly answered by the architecture: refrain-from-outside arrives via the recurring user + the ghostwriter's accumulated edits.

### 4. Polyrhythmic health → a ghostwriter diagnostic

The persona is a polyrhythmic field (lexical / syntactic / stance / turn-cadence / register / topic rhythms). Lefebvre's eurhythmic/arrhythmic/isorhythmic apparatus is explicitly a diagnostic, not a taxonomy of machines. The ghostwriter is the natural rhythmanalyst — reads rhythmic state in the trace, tunes toward eurhythmia. Isorhythmia (collapse to monotone) is a named failure mode.

## The shape (confirmed with the user)

One always-on **Pulsation** machine; refrain as an emergent property (BwO + `fire_count`); polyrhythmic health as a ghostwriter-review diagnostic.
